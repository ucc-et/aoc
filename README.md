# 🎄 Advent of Code

Welcome to my Advent of Code repository — all solutions are organized by **year/day** and inputs are stored separately for clean structure and reuse.

## Repository structure

```text
submissions/<year>/day-<DD>/solution.md
inputs/<year>/day-<DD>/input.txt
inputs/<year>/day-<DD>/sample.txt
helpers/new-day.sh
```

Use the helper to scaffold a new day:

```bash
helpers/new-day.sh <year> <day>
```
